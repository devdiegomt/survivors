# Instrucciones para el asistente

- **Antes de nada, lee `GAME.md`**: visión, reglas, decisiones y registro de cambios.
- Al terminar cada sesión, añade una entrada al registro de cambios de `GAME.md` y
  actualiza la estructura de carpetas y las decisiones si han cambiado.
- Usa la API de **Phaser 4**, no la de la 3. Ante la duda, consulta la carpeta `skills/`
  del repositorio oficial de Phaser (`phaserjs/phaser`).
- Enemigos, armas, mejoras y cualquier valor ajustable van como datos en `src/data/`,
  nunca dentro de la lógica.
- Explica cada decisión de arquitectura en una frase.
- Antes de hacer commit: `npm run build` debe pasar sin errores.
